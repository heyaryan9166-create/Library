Admin security

The app PIN is a local device lock, not a secure server-side login. Anyone with access to browser storage or the device may be able to bypass it. Use iPhone device security as well.

Cloud database setup

Cloud sync requires a Supabase project. Create a project, enable Email/Password Authentication, create the table using the SQL instructions below, then enter your project URL and anon key. Your data will sync under your signed-in admin account.
Cloud not connected.
Show required Supabase SQL setup 
create table public.library_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz default now()
);
alter table public.library_data enable row level security;
create policy "Users manage own library data"
on public.library_data for all
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
